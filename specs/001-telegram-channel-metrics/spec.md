# Feature Specification: Метрики аудитории Telegram-канала

**Feature Branch**: `001-telegram-channel-metrics`

**Created**: 2026-11-10

**Status**: Draft

**Input**: User description: "Первая административная панель для Telegram-канала. На текущий момент в ней нужно отображать количество пользователей канала, сколько из них удалённых и сколько реальных на текущий момент."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Просмотр текущего состава аудитории (Priority: P1)

Администратор открывает панель выбранного Telegram-канала и видит общее число текущих подписчиков, число удалённых аккаунтов среди них и число реальных подписчиков. Это позволяет оценить фактический размер аудитории без ручных подсчётов.

**Why this priority**: Эти три показателя составляют всю запрошенную ценность первой версии административной панели.

**Independent Test**: Открыть панель при известном составе аудитории и проверить, что все три показателя соответствуют одному актуальному снимку данных и правильно отображают долю реальных подписчиков.

**Acceptance Scenarios**:

1. **Given** в канале 1 000 текущих подписчиков, из которых 120 имеют удалённые аккаунты, **When** администратор открывает панель, **Then** он видит: всего — 1 000, удалённых — 120, реальных — 880, а также время формирования этих данных.
2. **Given** панель уже открыта, **When** администратор запрашивает обновление, **Then** все три показателя и время обновления заменяются значениями из одного нового снимка аудитории.
3. **Given** актуальные данные аудитории недоступны, **When** администратор открывает или обновляет панель, **Then** он видит понятное сообщение о недоступности, а устаревшие или неполные значения не выдаются за текущие.
4. **Given** пользователь не имеет прав администратора, **When** он пытается открыть панель, **Then** доступ к метрикам не предоставляется.

### Edge Cases

- В канале нет подписчиков: все три показателя равны нулю.
- Все подписчики имеют удалённые аккаунты: показатель реальных подписчиков равен нулю.
- Часть аккаунтов невозможно классифицировать: панель сообщает о недоступности полной классификации и не считает такие аккаунты реальными.
- Источник возвращает противоречивые значения, при которых сумма удалённых и реальных не равна общему числу: панель не показывает их как корректный актуальный снимок.
- Данные временно недоступны или устарели: панель явно обозначает это состояние.
- Показатели содержат большие числа: точные значения остаются читаемыми без потери точности.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST отображать метрики для одного заранее выбранного Telegram-канала.
- **FR-002**: System MUST отображать общее количество текущих подписчиков канала.
- **FR-003**: System MUST отображать количество текущих подписчиков с удалёнными аккаунтами.
- **FR-004**: System MUST отображать количество реальных подписчиков как разность между общим количеством текущих подписчиков и количеством удалённых аккаунтов среди них.
- **FR-005**: System MUST формировать все три показателя из одного снимка аудитории, чтобы исключить несогласованность из-за разного времени получения данных.
- **FR-006**: System MUST отображать дату и время последнего успешного обновления показателей.
- **FR-007**: System MUST обновлять показатели при открытии панели и предоставлять администратору возможность запросить повторное обновление.
- **FR-008**: System MUST предоставлять доступ к панели только авторизованным администраторам.
- **FR-009**: System MUST показывать понятное сообщение при невозможности получить или полностью классифицировать актуальные данные и MUST NOT представлять неполные или устаревшие данные как текущие.
- **FR-010**: System MUST отображать показатели как точные неотрицательные целые числа и обеспечивать равенство: общее количество = удалённые + реальные.

### Key Entities *(include if feature involves data)*

- **Telegram-канал**: Канал, состав аудитории которого просматривает администратор.
- **Снимок аудитории**: Состав текущих подписчиков канала на определённый момент; содержит общее, удалённое и реальное количество, а также время формирования.
- **Классификация подписчика**: Состояние аккаунта текущего подписчика — удалённый или реальный. Отсутствие классификации не приравнивается к реальному аккаунту.

### Scope Boundaries

- Первая версия поддерживает только один заранее выбранный канал.
- История изменений, графики, выгрузка данных, список подписчиков и управление каналом не входят в первую версию.
- Выявление ботов, фальшивых аккаунтов и накруток не входит в понятие «реальные подписчики» и не входит в первую версию.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Администратор может увидеть все три запрошенных показателя на одном экране без дополнительных переходов в 100% успешных загрузок панели.
- **SC-002**: В 95% успешных открытий панели актуальные показатели доступны администратору не более чем через 5 секунд.
- **SC-003**: Для 100% отображаемых снимков выполняется равенство «общее количество = удалённые + реальные», а значения соответствуют составу аудитории на указанное время.
- **SC-004**: В 100% случаев недоступности или неполноты данных администратор видит явное состояние ошибки вместо значений, выдаваемых за актуальные.
- **SC-005**: Не менее 90% администраторов, участвующих в приёмочной проверке, с первой попытки правильно называют текущее число реальных подписчиков без дополнительных пояснений.

## Assumptions

- Под «пользователями канала» понимаются его текущие подписчики, а не бывшие подписчики или пользователи, связанные с публикациями канала.
- Под «удалёнными» понимаются текущие подписчики, чьи аккаунты Telegram удалены.
- Под «реальными» понимаются текущие подписчики с неудалёнными аккаунтами; это не подтверждение того, что аккаунт принадлежит человеку или не является ботом.
- Канал выбран заранее, поэтому выбор и переключение каналов не требуются.
- Источник данных способен предоставить общее число подписчиков и классификацию их аккаунтов либо явно сообщить о невозможности полной классификации.
- «На текущий момент» означает самый новый доступный снимок при открытии или ручном обновлении панели, а не непрерывное обновление в реальном времени.
- Для просмотра панели уже существует или будет предоставлен механизм административного доступа; его способ не определяется этой спецификацией.
- Панель не раскрывает персональные данные отдельных подписчиков.
